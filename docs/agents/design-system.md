# ダッシュボードのデザインの決まり

## 目的

この文書は、ダッシュボードの見た目を作り直すときの正本である。
目標は Linear の密度と整い方で、Orca より迷わない画面にする。
実装者はここにある値だけを使う。ここにない値を足すときは、先にこの文書を直す。

## 現状の診断

2026-10-10 に 1440x900 と 390x844 で本番の画面を撮って確かめた。
撮った画像は `/Users/r/.claude/jobs/a305032f/tmp/design/before/` にある。

| 問題 | 根拠 |
| --- | --- |
| 区画の上端が揃わない | 左の見出しは上から 12px で高さ 28px、真ん中は 48px、右は 42px である。右はその下に「大きく開く」の 30px の帯が続く。 |
| 面の種類が多い | 会話に吹き出し、枠付きの依頼カード、利用者の青紫の面が並ぶ。右には灰色の地に角 12px のカードと点線の箱がある。 |
| 文字の段が多い | 10px、11px、12px、13px、14px、15px と太さ 400、500、550、600、700 が混ざる。左の 2 行目とグラフの補足は 10px で読みにくい。 |
| 選択が重い | 選んだセッションは紫の地と左の 2px の帯と角丸が重なる。グラフの根も紫の枠と紫の階調と左の 3px の帯を持つ。 |
| 会話の流れが切れる | 「ツールを N 件使用」が発言ごとに挟まる。強調の太字と枠付きの吹き出しで、本文より飾りが目立つ。 |
| 変更のタブが重い | 節の見出しが 15px の太字で、各節が枠で区切られる。木の開閉は既定の三角で、ファイルのタブの木と形が違う。 |
| 上書きの層が重なる | `styles.css` は前半の定義を後半の 230 行で上書きしている。同じ class の値が 2 か所以上にあり、どれが効くか読めない。 |
| 日本語で太さが効かない | 日本語の字形は W3 と W6 しか持たないことが多い。500 は 400 と同じに見えるので、名前の強調が効いていない。 |

## 原則

- 面は 3 種類だけにする。地、浮いた面、利用者の発言である
- 区別は色の明るさで付け、枠や影や帯を重ねない
- 強調の色は操作とフォーカスだけに使い、選択には使わない
- 状態は色の点と短い語で示し、札や塗りの面にしない
- 太さで階層を作らず、大きさと文字の色の段で作る

## 色のトークン

背景は 4 段にする。段が上がるほど濃くなる。

| 変数 | 明るい表示 | 暗い表示 | 使う所 |
| --- | --- | --- | --- |
| `--bg-0` | `#ffffff` | `#16171b` | 会話と右のパネルの地、カード、入力欄 |
| `--bg-1` | `#f7f7f8` | `#111215` | 左の区画の地、グラフの地、差分の見出し |
| `--bg-2` | `#f0f0f2` | `#1f2025` | 指を置いた行、利用者の発言、コードの地 |
| `--bg-3` | `#e8e8eb` | `#27282e` | 選んだ行、選んだタブ |

文字は 4 段にする。

| 変数 | 明るい表示 | 暗い表示 | 使う所 |
| --- | --- | --- | --- |
| `--fg-1` | `#1b1c20` | `#e8e9ec` | 本文、名前、選んだ項目 |
| `--fg-2` | `#5e6069` | `#a1a3ab` | 普通の行、操作の語、状態の語 |
| `--fg-3` | `#8b8d96` | `#6f717a` | 時刻、モデル名、節の見出し |
| `--fg-4` | `#b4b6bd` | `#4d4f57` | 入力の手本、行番号、使えない操作 |

線と強調とフォーカスは次の値にする。

| 変数 | 明るい表示 | 暗い表示 | 使う所 |
| --- | --- | --- | --- |
| `--line` | `#e6e6e9` | `#2a2b31` | 全ての枠と区切り。線はこの 1 色だけにする。 |
| `--accent` | `#5e6ad2` | `#7b84e6` | 主ボタン、フォーカス、リンク、送信 |
| `--accent-hover` | `#4f5bc4` | `#8c94ec` | 主ボタンに指を置いたとき |
| `--on-accent` | `#ffffff` | `#ffffff` | 主ボタンの文字 |
| `--focus` | `rgb(94 106 210 / 0.35)` | `rgb(123 132 230 / 0.45)` | フォーカスの輪の色 |

状態は 6 色にする。点の色と、失敗とあなたの番の語の色に使う。

| 変数 | 状態 | 明るい表示 | 暗い表示 | 印 |
| --- | --- | --- | --- | --- |
| `--state-running` | 実行中 | `#1f9d55` | `#3fbf7a` | 塗った点が脈打つ |
| `--state-approval` | 承認待ち | `#d97706` | `#f0a03c` | 塗った点 |
| `--state-reply` | 返答待ち | `#2f7fd8` | `#5aa2f0` | 塗った点 |
| `--state-failed` | 失敗 | `#d93a3a` | `#f06464` | 塗った点。語も同じ色にする。 |
| `--state-done` | 完了 | `#7c8db5` | `#93a3c8` | 塗った点 |
| `--state-idle` | 待機 | `#a1a3ab` | `#6f717a` | 中を抜いた輪 |

差分とファイルの色は状態の色から取る。

| 変数 | 明るい表示 | 暗い表示 |
| --- | --- | --- |
| `--diff-add-bg` | `#e8f6ed` | `#12291c` |
| `--diff-add-fg` | `#17643a` | `#86e3ad` |
| `--diff-del-bg` | `#fdeded` | `#331a1c` |
| `--diff-del-fg` | `#a02429` | `#ffa5a8` |

ファイルの印は、追加を `--state-running`、変更を `--state-approval` にする。
削除は `--state-failed`、名前の変更は `--state-reply` にする。
字句の色は `highlight.css` の `--tok-*` をそのまま残す。
提供元の色は `--provider-claude: #d97757` と `--provider-codex: #10a37f` にし、16px の印だけで使う。

## 文字のトークン

書体は `--font` と `--mono` の 2 つにする。`--font` は Inter の次に `"Hiragino Sans"` と `"Noto Sans JP"` を足す。
太さは 400 と 600 の 2 つにする。500 は日本語で 400 と同じに見えるので使わない。

| 変数 | 大きさ | 行の高さ | 太さ | 使う所 |
| --- | --- | --- | --- | --- |
| `--type-title` | 15px | 24px | 600 | 区画の見出しの名前、会話の名前、頁の題 |
| `--type-body` | 14px | 22px | 400 | 会話の本文、入力欄、設定の項目 |
| `--type-ui` | 13px | 20px | 400 | 行の名前、タブ、ボタン、ツールの行 |
| `--type-meta` | 12px | 16px | 400 | 時刻、モデル名、状態の語、節の見出し |
| `--type-mono` | 12px | 18px | 400 | コード、差分、パス、ハッシュ |

- 変数は `font` の短縮形で書く。例は `--type-ui: 400 13px/20px var(--font)` である
- 11px 以下は使わない。`kbd` も 12px にする
- 本文の中の Markdown の見出しは、h1 から h3 を `--type-title` にする
- h4 以下は `--type-body` の 600 にする。本文の `strong` は 600 のまま残す
- 字間は全て 0 にする。`letter-spacing` と大文字化は使わない

## 余白のトークン

余白は 4px の刻みにし、次の 7 つだけを使う。

| 変数 | 値 | 主な使い道 |
| --- | --- | --- |
| `--space-1` | 4px | 印と語の間、行と行の間 |
| `--space-2` | 8px | 行の左右の内側、ボタンの並び |
| `--space-3` | 12px | カードの内側、入力欄の内側 |
| `--space-4` | 16px | 区画の左右の内側、発言と発言の間 |
| `--space-6` | 24px | 会話の左右の内側 |
| `--space-8` | 32px | 空の状態の内側、頁の左右 |
| `--space-12` | 48px | 頁の上下の外側 |

高さは 3 つに揃える。`--row` は 32px、`--control` は 28px、`--header` は 48px である。
3px、5px、6px、7px、10px、14px、18px は全て最も近い刻みに丸める。

## 角と線と影と動き

| 変数 | 値 | 使う所 |
| --- | --- | --- |
| `--radius-1` | 6px | 行、ボタン、入力、タブ、ツールの行、コード |
| `--radius-2` | 10px | カード、入力欄の箱、利用者の発言、浮いた面 |
| `--border` | `1px solid var(--line)` | 全ての枠と区切り |
| `--shadow` | `0 8px 24px rgb(15 17 26 / 0.12)` | 浮いた面だけ。暗い表示は `rgb(0 0 0 / 0.5)` にする。 |
| `--duration` | 120ms | 色、透明度、開閉の向き |
| `--ease` | `cubic-bezier(0.2, 0, 0, 1)` | 全ての動き |

- 点と提供元の印は円にする。円は角のトークンに数えない
- 線は 1px だけにする。点線、破線、2px 以上の帯は使わない
- 推定の情報は破線をやめ、`--fg-3` の語で「推定」と書く
- フォーカスは `outline: 2px solid var(--focus)` と `outline-offset: 1px` にする
- 浮いた面は通知、メニュー、Cmd+K、グラフの拡大の操作、右の重ね表示である
- 繰り返す動きは実行中の点の脈だけにする。周期は 1600ms とする
- `prefers-reduced-motion` では脈と開閉の動きを止める

| 区画 | 幅 | 地 | 見出し |

| 左 | `--sidebar-width: 248px` | `--bg-1` | 48px。製品名と検索と通知を置く。 |

- 右の幅は 320px から画面の 50% までつまめる。閉じたら幅 0 にする
- 右の「大きく開く」の帯は消し、見出しの右に 28px の印のボタンとして置く
- 子の会話の「戻る」の 40px の帯は消し、会話の見出しに道順として入れる
- 会話の本文と入力欄は、幅 720px を上限に真ん中に置く
- 左の上の一覧、承認待ち、検索の 3 つの行は見出しの下に 32px の行で縦に並べる

画面の幅による切り替えは次のとおりにする。

| 幅 | 配置 |
| --- | --- |
| 1280px 以上 | 3 区画を並べる。右の既定の幅は 420px である。 |

下のタブはセッション、会話、パネルの 3 つにする。
選んだタブは `--fg-1` の語と印にし、地の色は変えない。下のタブの上に `--border` を引き、`env(safe-area-inset-bottom)` の分だけ下を空ける。

## 左の区画

### セッションの行

1 行 32px の 1 行表示にする。左から状態の点、名前、右端の時刻の順に並べる。

| 状態 | 見た目 |
| --- | --- |
| 普通 | 名前は `--type-ui` の `--fg-2` にする。時刻は `--type-meta` の `--fg-3` にする。 |
| 指を置いた | 地を `--bg-2` にする。名前を `--fg-1` にする。 |
| 選んだ | 地を `--bg-3` にし、名前を `--fg-1` にする。左の帯と強調の色は使わない。 |
| あなたの番 | 点を承認待ちか返答待ちの色にする。時刻の代わりに「承認待ち」か「返答待ち」をその色で書く。 |
| 実行中 | 点を `--state-running` で脈打たせる。時刻の代わりに経過を `--fg-3` で書く。 |

- 点の枠は 16px にし、行の左の内側は `--space-2` にする
- 行の角は `--radius-1`、行と行の間は 0 にする
- 子の数や 2 行目の補足は行に出さない。必要なら `title` に入れる
- 群の見出しは 28px の `--type-meta` の `--fg-3` にし、行の名前と左を揃える
- 群は、あなたの番、実行中、最近、以前の順にする。以前は畳んで件数だけ出す

### プロジェクトの行

- 高さは 32px にし、左から開閉の印、フォルダの印、名前を並べる
- 開閉の印とフォルダの印は 16px の `--fg-3` にする
- 名前は `--type-ui` の `--fg-1` にする。太字にしない
- 右端に実行中の数を `--type-meta` の `--fg-3` で出す。0 なら何も出さない
- 「+」のボタンは指を置いた行だけに出す
- セッションの行はプロジェクトの名前の左端に揃えて字下げする

## 会話

### 会話の見出し

- 高さ 48px、左右の内側は `--space-6` にする
- 名前は `--type-title` にし、続けて状態の印とモデル名を `--type-meta` で並べる
- 子の会話は、根の名前を `--fg-3` で書き「/」で子の名前に続ける。根の名前は押せる
- 右端に「詳細」と「変更したファイル」を ghost の小さいボタンで置く
- 詳細を開いた中身は見出しの下に `--bg-1` の帯で出し、枠の箱にしない

### 利用者の発言

- 右に寄せ、幅は本文の 80% を上限にする
- 地は `--bg-2`、角は `--radius-2`、内側は `--space-2` と `--space-3` にする
- 文字は `--type-body` の `--fg-1` にする。青や紫の地は使わない
- 送り主の行は出さない。時刻は指を置いたときだけ左に `--type-meta` で出す
- 子の会話で根からの依頼は、上に「根からの依頼」を `--type-meta` で添える
- 長い依頼は 8 行で切り、「全文を開く」を ghost の小さいボタンで置く

### エージェントの発言

吹き出しにしない。枠も地もない本文にする。

- 本文は左に寄せ、幅 720px の全てを使う。`--type-body` の `--fg-1` にする
- 送り主の行は、同じ送り主が続く最初の 1 回だけ出す
- 送り主の行は名前を `--fg-2`、時刻を `--fg-3` にし、どちらも `--type-meta` にする
- 発言と発言の間は `--space-4`、同じ送り主が続くときは `--space-2` にする
- 段落の間は 8px、箇条の間は 4px にする
- インラインのコードは地を `--bg-2`、文字を `--fg-1` にし、赤くしない
- コードの塊は地を `--bg-1`、角を `--radius-1`、枠を `--border` にする

### ツールの畳み

- 1 つの返答の中のツールの呼び出しは、まとめて 1 行に畳む
- 返答の途中で何度も出ても、1 つの返答につき 1 行にする
- 行は 28px、`--type-meta` の `--fg-3` にし、地も枠も付けない
- 語は「ツール 8 件」とし、続けて使った名前を 3 つまで「·」でつなぐ
- 失敗を含むときは、件数の後に「失敗 1」を `--state-failed` で書く
- 指を置いたら地を `--bg-2` にし、開いたら印を 90 度回す
- 開いた中身は 1 件 28px の行で並べ、左を `--space-4` だけ字下げする
- 1 件を開いた詳細は `--bg-1` の地に `--type-mono` で出す。枠の箱を重ねない

### 依頼のカード

- 高さ 40px の 1 行にし、枠は `--border`、角は `--radius-1`、地は `--bg-0` にする
- 左から提供元の 16px の印、依頼の名前、右端の状態の印を並べる
- 名前は `--type-ui` の `--fg-1` にする
- 指を置いたら地を `--bg-2` にする。押すと右のグラフでその子を選ぶ
- 子の報告の畳みも同じ形にし、名前の代わりに報告の 1 行目を出す
- 承認を待つ依頼は、カードの下に続けて承認の行を置く。枠は 1 つにまとめる

### 入力欄

- 箱は地 `--bg-0`、枠 `--border`、角 `--radius-2` にし、影を付けない
- フォーカスしたら枠を `--accent` にする。輪の影は付けない
- 文字は `--type-body`、内側は `--space-3` にし、高さは 48px から 200px まで伸ばす
- 下の帯は 40px にし、左にモデルと深さの選択を ghost の小さい形で置く
- 右に送信の主ボタンを置く。送れないときは地 `--bg-2` と語 `--fg-4` にする
- 「中断」は実行中だけに出す。secondary の小さいボタンにする
- 読むだけのときは地を `--bg-1` にし、理由を `--type-meta` で添える

## 右のパネル

### タブ

- 見出しの 48px の中に、高さ 28px の区切りボタンとして並べる
- 語は `--type-ui` の `--fg-2`、角は `--radius-1`、左右の内側は `--space-3` にする
- 選んだタブは地 `--bg-3` と語 `--fg-1` にする。下線は引かない
- 右端に「大きく開く」と「閉じる」を 28px の印のボタンで置く
- パネルの中の地は `--bg-0` にする。中を灰色の地にしない

### グラフのノードと線

- 拡大の操作は浮いた面にし、`--radius-2` と `--shadow` を付ける
- 全画面の上の帯は 48px にし、「根の会話」の小さな見出しを消す

### 変更

- 節の見出しは 32px の `--type-meta` の `--fg-3` にし、太字と枠の箱をやめる
- 節の間は `--border` の横線 1 本で区切る
- コミットの行は 44px にし、件名を `--type-ui`、2 行目を `--type-meta` にする
- 選んだコミットは地を `--bg-3` にする。強調の色の地は使わない
- 枝の名前と会話の印は `--type-meta` の `--fg-3` の語にし、塗った札にしない
- 変更したファイルの木は、ファイルのタブと同じ木の部品を使う

### 差分

- ファイルごとの外枠の箱をやめ、ファイルの見出しで区切る
- 見出しは 36px、地 `--bg-1`、下に `--border` を引く

- 行は `--type-mono` にし、行番号は `--fg-4` にする
- 追加と削除の行は地だけを色にし、文字は `--fg-1` のまま読めるようにする
- 区切りの `@@` の行は地 `--bg-1`、文字 `--fg-3` にする
- 選んだ行は地を `--bg-3` にし、内側の 2px の枠をやめる

- 1 段ごとに 16px 字下げし、開閉の印とファイルの印は 16px の `--fg-3` にする

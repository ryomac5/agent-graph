# 用語集

## 方針

本稿はダッシュボード画面の日本語表示を統一するために従うべき用語基準を定めます。
開発者が日常的に使う自然な表現を選び直訳調や過度に硬い漢語は用いない方針とします。
技術分野で広く定着しているカタカナ語は無理に和訳せずそのまま表記することとします。

## 用語基準

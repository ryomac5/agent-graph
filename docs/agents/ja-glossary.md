# 用語集

## 方針

本稿はダッシュボード画面の日本語表示を統一するために従う用語基準を定める。
画面の日本語表示には、開発者が日常の開発業務で親しんでいる自然な表現を採用する。
英語の直訳調や過度に硬い漢語は避け、使う人に意図や実際の動作がすぐ伝わる語を選ぶ。
技術分野で広く定着しているカタカナ語は無理に和訳せずそのまま表記することとする。

## 依頼

サブエージェントは相手のエージェントを指し、依頼は頼んだ作業実体を指す。
親エージェントは「依頼元」、委譲された作業は「受けた依頼」と呼ぶ。
ナビゲーションやグラフの表示でも、エージェントを指す場面ではサブエージェントを用いる。

## デフォルトと標準

初期設定値や未指定時の選択肢など default に当たる概念には「デフォルト」を用いる。
規格や基準など standard に当たる概念には「標準」を用いる。
これにより「標準モデルを使用」と「デフォルトのモデル」の混同を防ぐ。

## 第2版で新設・残存した問題

### R1【必須】終了を試みた記録を、終了した証拠にしている

**推測。** Stop hookが続行を要求した途中や、報告失敗から復旧している途中にIdleを表示する。

**直すこと。** モデル応答・報告の配達・turnの終了を分ける。handbackのtool_resultはreportedの証拠に限定し、turn終了へ流用する規則を削る。Stopはイベント名だけで採用せず、終端を認める形式と続行時の扱いを定める。偽CLIに「Stop attachment→hookによる続行」「handback失敗→道具継続」を加え、その中間でcompletedにならないことを固定する。

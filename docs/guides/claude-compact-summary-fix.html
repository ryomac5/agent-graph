Claude の圧縮要約の誤表示を修正

2026-10-13。圧縮要約・内部メタ・履歴表示専用の行を、人の発言から除外する。実装と検証だけを行い、本番の履歴・台帳・.endpoint は変更していない。API / runner の再起動、commit、push も行っていない。

原因と経路

  1. observe/history-kinds.ts は Claude の type: user を message に分類し、トップレベルの旗を見ていなかった。
  2. observe/claude/index.ts は message.created を source=transcript-claude、source_event_id=message:["claude",uuid]、role=user で追記し、会話への有効な所属も作った。保存した payload には元の旗がなかった。
  3. core/ledger/projections/messages.ts はその発言と所属を投影し、ProjectionFeed.conversation() が画面へ配信した。画面の senderOf() は通常の user の文字列を人の列に置き、元の時刻を表示した。
  4. core/ledger/turns.ts の除外は実行状態の判定だけに適用される。発言の取り込みを止めるものではなかった。棚卸しも type/subtype だけだったため、圧縮要約が通常の user に埋もれた。

修正

isCompactSummary、isMeta、isVisibleInTranscriptOnly が true の行を発言として取り込まない。状態判定と既存発言の除外は core の共通の旗判定を使う。圧縮境界は既存の compacted 関係のまま残す。

本文の定型句では除外しない。同じ文を引用した実際の発言、false の旗、子の会話、画像、道具の結果、queueSkipAttachments などが付く通常の入力を保持する。未知の旗は observation.unsupported に記録し、人の発言へ暗黙に分類しない。

棚卸しは user / assistant のトップレベルの boolean と isXxx の旗を、名前と値で分類する。真偽値でない isXxx は <invalid> にする。未分類の旗だけでも終了コード 1。見本には旗の真偽値を残すが、本文・識別子・不正な旗の値は伏せる。複数の旗がある場合は非発言の分類を優先する。

既存行と再構築

読み取り位置に claudeMessageFlagsVersion=1 を追加した。新しい API の起動後の通常走査で、版のない Claude ファイルは更新がなくても一度読み直す。旧い cursor より前にある旗付き行には、元の発言を supersedes で指す message.corrected を追記する。訂正には UUID と transcript_flags だけを持たせ、元の source_event_id・payload・本文を変更しない。

訂正後は発言・所属・仮の会話名の候補・検索から除外する。通常の差分投影で一覧の件数と最終発言時刻を更新し、開いている画面へ削除差分を配る。送信の見張りが照合する発言にもならない。新しい取り込みでは run・未読の根拠となる状態と活動時刻・Queued の入力を変えない。

投影版の引き上げと offline rebuild は不要。 旧い事実の読み方を一括変更するのではなく、追加した訂正が影響する発言だけを通常の差分処理で再投影する。補完の完了は cursor に保存し、再起動・再送・途中停止でも訂正を増殖させない。全件 rebuild と差分反映の一致も試験している。

反映手順は、変更を通常の手順で導入し、API を起動し直して最初の履歴走査と投影が完了するのを待つこと。runner の再起動や手動の台帳編集は不要。この作業では実行していない。元履歴を失った行は旗を復元できないため、本文から推測して除外しない。

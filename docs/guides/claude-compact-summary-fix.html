既存行の訂正と rebuild

claudeMessageFlagsVersion=1 を維持した。本番に message-flags: の訂正事実がないことを読み取りで確認済み。旧い cursor のファイルを通常走査で一度読み直し、旗付きの既存発言へ message.corrected を追記する。隠す行と残す行の両方に旗を補い、新規取り込みと同じ正規化・表示・検索の規則を適用する。元の事実と本文は変更しない。

履歴を先頭から再読した場合も、旧い message.created の payload を変えず、同じ訂正で旗を補う。再送・再起動・途中停止で訂正を増殖させない。

すでに 3e64c84 で旗の補完を済ませ、notification として投影した別の台帳では、コードの差し替えだけでは既存投影が更新されないため rebuild が必要である。今回はその条件に当たらず、本番の rebuild は実行していない。

新しいMacへの導入

Apple Silicon / IntelのMacで、ターミナルに次の1行を貼り付けます。

curl -fsSL https://raw.githubusercontent.com/ryomac5/agent-graph/main/scripts/install.sh | bash

コードを取得し、未導入のNode 24・Claude Code・Codex CLI・Herdrを公式配布から導入します。HomebrewやGitの事前準備は不要です。Nodeは公式チェックサムとの一致を確認してから実行します。

Claude / Codexのログイン画面が開いたら、自分のアカウントでログインします。Gitの実行環境がないMacでは、Command Line Toolsの確認画面が開きます。インストールを選ぶと、セットアップが完了を待って先へ進みます。

その後、Claudeのプラグイン・CodexのMCP・Herdrの連携を登録し、バックグラウンド起動します。最後に表示されたダッシュボードのURLを開いてください。導入したCLIのPATHも登録するので、通常のCLIを使う場合は新しいターミナルを開きます。

開いているClaude / Codexは設定を読み直すために再起動します。次回のPCログインからデーモンと画面操作用サーバーは自動起動します。既にHerdrサーバーが動いている場合は、そのサーバーを利用して再起動しません。

公式配布と認証：Node / Claude Code / Codex CLI / Herdr。各サービスの利用にはそれぞれのアカウント・利用条件が適用されます。

確認と更新

agent-graph --doctor
agent-graph --dry-run

--doctorは登録状況とURLを表示します。--dry-runは変更予定を表示します。どちらもツールの導入・設定変更・再起動は行いません。

agent-graphの更新も最初と同じ1行で行います。コードは版ごとのフォルダに保存し、以前の版を上書きしません。設定が変わらなければデーモンを再起動しません。再起動が必要な変更で実行中の委譲がある場合は中止し、完了後の再実行を案内します。

Gitで取得して開発する場合は、リポジトリのルートで bash scripts/setup.sh を実行しても同じセットアップになります。自動化用の --skip-login はログイン確認のみを省略するため、委譲を使う前に別途認証を完了してください。

設定と保存先

内容既定の場所
取得したコード~/.local/share/agent-graph/releases/
自動導入したNode・Codex・Herdr~/.local/share/agent-graph/tools/
Claude Code~/.local/bin/claude
Codex設定~/.codex/config.toml
Claudeプラグイン~/.local/share/agent-graph/marketplace/
自動起動~/Library/LaunchAgents/dev.agent-graph.daemon.plist
dev.agent-graph.herdr.plist
デーモンのログ~/.local/state/agent-graph/run/
ターミナルのPATH~/.zprofile（Bashは~/.bash_profile）のagent-graph専用枠

Codex設定はagent-graphの項目だけを更新し、他のモデル設定やMCPサーバーを保持します。変更前のCodex設定とシェル設定を .agent-graph.bak に保存します。Herdr自身の連携は公式integrationコマンドで登録します。CODEX_HOMEやXDGの保存先を使う場合は絶対パスを指定してください。

新しいPCで設定を生成するため、古いPCのLaunchAgentや生成済みプラグインはコピーしません。個人の割り当てを引き継ぐ場合だけ ~/.config/agent-graph/policy.toml を移してください。セッション履歴の移行はセットアップには含みません。

起動に失敗した場合は表示されたエラーと daemon.stderr.log を確認します。Herdr用のログは run/herdr/ にあります。ポートは AGENT_GRAPH_PORT または ~/.config/agent-graph/config.toml の [dashboard] port で指定できます。

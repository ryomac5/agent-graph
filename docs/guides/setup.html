新しいMacへの導入

リポジトリを新しいMacに置いたら、そのフォルダで実行します。

bash scripts/setup.sh

常駐起動、Claudeのユーザー登録、Codexの設定をまとめて行い、最後にダッシュボードのURLを表示します。そのURLをブラウザで開いてください。開いているClaude / Codexは設定を読み直すために再起動します。次回のPCログインからデーモンは自動起動します。

最初に用意するもの

  • Node 24以上。未導入でもHomebrewがあればセットアップが node@24 を導入します。Homebrewがない場合は Nodeの公式サイトから導入してください。pnpmや実行用の依存インストールは不要です。
  • Claude Code / CodexのCLIとログイン。利用する側を各PCで準備してください。CLIがない場合は不足を表示します。後から導入して同じセットアップを再実行すると登録できます。
  • Herdr。画面から新規セッションの起動・メッセージ送信・モデル変更を使う場合に必要です。未導入の場合、これらの操作は使えません。

CLIを導入済みなら、ログインはそれぞれ次のコマンドで行います。

claude auth login
codex login

公式の導入・認証手順：Claude Code / Codex CLI。Claudeはユーザー範囲のプラグインとして登録します。Codexは個人設定にMCPサーバーを追加します。

移すのはコード。設定は新しいPCで生成

この変更を含むリポジトリを新しいPCへコピーして実行してください。新しいPCのNodeやCLIの場所を検出して設定を生成するため、古いPCのLaunchAgentや生成済みプラグインをコピーする必要はありません。公開済みの版を使う場合は、取得後に同じコマンドを実行します。

git clone https://github.com/ryomac5/agent-graph.git
cd agent-graph
bash scripts/setup.sh

アカウントのログインは各PCで行います。割り当てポリシーを引き継ぐ場合だけ、~/.config/agent-graph/policy.tomlを移してください。セッション履歴の移行はセットアップには含みません。

確認と更新

bash scripts/setup.sh --doctor
bash scripts/setup.sh --dry-run

--doctorは登録状況とURLを表示します。--dry-runは変更予定だけを表示し、Nodeの導入も設定変更も行いません。

コードを更新した後も同じセットアップを実行します。同じ設定ならデーモンを再起動しません。再起動が必要な変更で実行中の委譲がある場合は、完了後の再実行を案内します。

設定とログ

内容既定の場所
Codex設定~/.codex/config.toml
変更前のCodex設定~/.codex/config.toml.agent-graph.bak
Claudeプラグイン~/.local/share/agent-graph/marketplace/
自動起動~/Library/LaunchAgents/dev.agent-graph.daemon.plist
デーモンのログ~/.local/state/agent-graph/run/

Codexはagent-graphの項目だけを更新し、他のモデル設定やMCPサーバーは保持します。Claudeにすでに同名のローカル登録がある場合はその場所を利用します。CODEX_HOMEやXDGの保存先を使う場合も絶対パスを指定すれば尊重します。

起動に失敗した場合は表示されたエラーと daemon.stderr.log を確認してください。ポートは AGENT_GRAPH_PORT または ~/.config/agent-graph/config.toml の [dashboard] port で指定できます。

# S4: 複製と compact

Claude jsonl のキー構造を写し、本文・識別子・パスは架空とした。
2026-10-07 のレビューで実測された対応版 `2.1.285`〜`2.1.291` のうち、
S4 は `2.1.288`〜`2.1.291` を固定する。残りの3版は S1 に置く。
`expected.json` は初期台帳の事実と、取り込み後の事実の種類別件数と投影の期待値。

二つの独立した fork のファイルに同じ uuid の発言が複製される。
共有発言は一件、所属は三件。明示された native の fork 関係はないため
forked の確定関係は推測しない。compact は親会話の自己関係となる。
要約は別の発言。subagents の sessionId は親を指すためファイル名を識別に使う。
親は初期台帳の host-claude の事実で origin=managed として登録する。
履歴には環境変数の欄を作らず、観測は既存の origin を引き継ぐ。
発言の出所は transcript-claude のままホストの優先規則に委ねる。

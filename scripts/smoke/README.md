# 核の使い方の確かめ

本番のダッシュボードで、核の使い方を本物のブラウザで通す。
本番に出すたびに、リポジトリの根で `node scripts/smoke/core-journeys.mjs` を走らせる。
通らなければ、本番に出したとは言わない。

- 確かめるのは送信、画像付きの送信、Codex の送信の経路、グラフ、変更、ファイル、名前の変更、設定、画面の誤りの 9 つである。
- 手順ごとに合否と秒数を 1 行で出す。
- 1 つでも落ちると、終了コードは 1 になる。
- 落ちた手順のスクリーンショットは `~/.cache/agent-graph/smoke/` に置く。
- 確かめ用のセッションは agent-graph のプロジェクトに 1 つだけ作り、モデルは haiku にする。
- その会話の id は `~/.cache/agent-graph/smoke/session.json` に覚え、2 回目からは呼び戻す。
- 作り直したいときは、`session.json` を消してから走らせる。
- 画面の WebSocket は台本が中継し、確かめの送信と名前の変更のほかの書き込みを止める。
- Codex の会話では送信を押すが、命令は中継で止まり、本物の Codex には届かない。
- 終わると、名前を戻し、確かめ用のセッションの端末を閉じ、localStorage を戻す。
- 宛先は `AGENT_GRAPH_SMOKE_URL` で変えられ、既定は `http://127.0.0.1:7420` である。
- Playwright が見つからないときは、台本の頭の `PLAYWRIGHT` の場所を直す。
